# 群星 Qunxing

用 AI 探索开放数学问题，用 Lean 检验结果。可以验证的贡献，会在星图上点亮一颗星。

## 现在的进度

- 桌面端测试版正在开发，稳定后在这里开源。
- 网站（qunxingmath.org）正在搭建。

## 参与

- 贡献方式见 [CONTRIBUTING](https://github.com/qunxingmath-org/qunxing-app/blob/main/CONTRIBUTING.md)。每个提交都要签名（`git commit -s`）。
- 发现安全问题，请按 [SECURITY](https://github.com/qunxingmath-org/qunxing-app/blob/main/SECURITY.md) 私下报告。
- 请不要让 Agent 代你点星、评论或刷量。

## 声明

- 群星记录提交的材料和本机检查参数，不对结果的正确性负责。
- "点亮"的含义，以网站上的《群星研究守则》为准。
- "群星"的名称和标志不在开源许可之内。

## English

Qunxing (群星, "the stars") is an open-source project for exploring open mathematical problems with AI. Results are checked in Lean, and each verifiable contribution lights a star on a public star map.

- **Status:** the desktop app is in early testing; the website (qunxingmath.org) is under construction.
- **Contributing:** see CONTRIBUTING.md in any repository. Every commit needs a DCO sign-off (`git commit -s`).
- **Security:** please report vulnerabilities privately; see SECURITY.
- **Disclaimer:** Qunxing records submitted material and local check parameters. It does not vouch for the correctness of results.
